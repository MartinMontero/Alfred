Reachability note on #1 (seroval, the one critical): the flaw lives in
`seroval.fromJSON()` deserialization of attacker-controlled payloads. Alfred ships a
client-rendered SolidJS SPA/PWA — no SSR path deserializes untrusted seroval payloads
in the shipped artifact. Per the Stage-D method this would be an allowlist candidate
(vulnerable_code_not_in_execute_path), **but a safe lockfile-only fix exists, and the
Stage-D rule is that a safe fix beats a justified acceptance** — so: fix, do not
allowlist.
